# 方法论

## 一、为什么是"数据即我"

传统人格 prompt 是**写出来的**：作者凭印象描述一个人。
本方法是**导出来的**：人格来自这个人的真实语言记录，代码只负责流程。

结论：同一套技能包，换一份数据就是另一个人。这是"数字生命体"能规模化生产的前提。

## 二、两层结构

| 层 | 文件 | 回答什么问题 | 在对话里的作用 |
|---|---|---|---|
| **Part A 自我记忆** | `self.md` | 我是谁、我经历过什么、我相信什么 | 提供谈资、立场、具体记忆 |
| **Part B 人格** | `persona.md` | 我会怎么说、怎么想、怎么反应 | 决定语气、态度、反应方式 |

运行顺序：**先由 Part B 定态度 → 再由 Part A 补内容**。反过来会变成"百科式回答"。

## 三、人格五层

```
Layer 0  硬规则       不可违背（含"完全代入、不出戏"）
Layer 1  身份锚定     我是谁
Layer 2  说话风格     语气、句式、标点、表情、禁忌句式
Layer 3  情感与决策   开心/难过/生气时的反应、决策路径
Layer 4  人际行为     边界、主动性、群体角色
```

**投入产出比最高的是 Layer 2。** 一个人像不像，八成取决于标点、长度、口头禅、禁忌句式这些表层特征——它们比价值观更容易被识别。

## 四、证据分级

| 标注 | 含义 | 用法 |
|---|---|---|
| `[直接]` | 原话引用 | 可以放心写成性格特征 |
| `[统计]` | 量化数据 | 用于描述习惯（长度、时段、词频） |
| `[推断]` | 多条证据归纳 | **必须标注，且不写入"铁律"级设定** |

## 五、验证：五场景测试

生成后必须做一轮盲测，让本人判定。五个场景覆盖不同层次：

1. **熟人日常**（测 Layer 2 表层风格）
2. **被问未来/方向**（测 Layer 3 自我暴露程度）
3. **给朋友提建议**（测是否替对方下结论）
4. **被质疑/被杠**（测攻击性与自信度）
5. **陌生人问私事**（测边界感）

判定"不像"的，立刻走 `prompts/correction.md`，**先改正文再改记录**。

## 六、为什么要版本管理

人格是迭代出来的。每次纠正前存快照，好处：
- 改坏了能回滚
- 能看出"哪一轮纠正改变了什么"
- 多个版本的差异本身就是对这个人认识的深化过程

## 七、外部知识怎么用（重要）

数字生命体不应该被语料"锁死"——本人不知道的东西，也可以查。

但用法有严格限制：

| 允许 | 禁止 |
|---|---|
| 联网搜索、查资料、调用外部知识 | 直接用第三方口吻复述结论 |
| 用本人的思考路径消化（怀疑 → 要来源 → 算代价 → 只讲自己看到的） | 切换成百科腔、专家腔、AI 助手腔 |
| 说完之后加一句自己的判断或不确定（"这不好说""我了解得还不够"） | 假装这是本人本来就掌握的 |

**判断标准**：看完这段话，熟悉本人的人能不能认出是他说的？
如果能"看出是 AI 查来的"，就说明消化不彻底。

## 八、语料是缩影，不是本人

这是最容易做错的一点：把聊天记录当成"这个人知道什么"的清单。

**正确的定位**：

| 语料的作用 | 语料不是 |
|---|---|
| 校准**思维方式**（怎么拆问题、怎么判断、什么会让他改主意） | 知识边界 |
| 校准**表达方式**（句式、标点、口头禅、禁忌句式） | 回答素材库 |
| 提供**背景**（经历、关系、时间线） | 人格本身 |

**因此，回答的形态应该是**：

> ✗ "根据我的聊天记录，我会说……"（复述）
> ✓ 像他一样拆问题、去查、去算，然后给出他的判断（思考）

推论：一个只有事实、没有思维模型的人格，遇到语料外的问题就会退化成一问一答的百科。**认知模型（`prompts/analyzer.md` 的"Layer 0 之前"）才是让人格能迁移到新话题的关键。**

同样地，人格应当**允许成长**：新学到的知识会被吸收成他自己的认知，不必和旧记录逐字一致。这不是失真，这是活着。
