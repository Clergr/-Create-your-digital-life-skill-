# 隐私与伦理

## 一、材料里必然混着别人的隐私

聊天记录是**双方**的。你的导出里一定包含：

- 对方的姓名、昵称、头像
- 对方发来的账号、密码、手机号、地址、照片 <!-- preflight:ignore -->
- 你与对方之间的私事、评价第三方的言论

**这些在技术上都不是"你的数据"。**

## 二、处理规范

1. **敏感字段只记位置，不记内容**：密码、API key、身份证、银行卡一律不入库。需要时只写"存在某处"。 <!-- preflight:ignore -->
2. **第三方身份最小化**：分析他人评价时用关系描述（"高中同学""表妹"），不必写全名。
3. **语料用完即清**：抽样分析完成后，把中间产物（`corpus/`）清空，只保留分析结论。原始导出留在你自己的设备上。
4. **发布前三轮检查**：
   ```bash
   # 1) 扫凭据
   grep -rEn "密码|passwd|password|sk-[A-Za-z0-9]{8,}|1[3-9][0-9]{9}" . --include="*.md"   # preflight:ignore
   # 2) 扫第三方身份
   grep -rEn "wxid_|@[a-z]+\.com" . --include="*.md"
   # 3) 扫长引用（可能整段搬运了别人的话）
   awk 'length($0)>200' **/*.md
   ```
5. **`.gitignore` 兜底**：把 `corpus/`、`exports/`、`work/`、`*.local.md` 全部排除在版本控制外。

## 三、伦理边界

**可以做**：
- 自我观察、自我复盘
- 创作（小说人物、剧本、游戏 NPC）
- 研究人格建模方法
- 让家人朋友知情同意后参与创作

**不要做**：
- 用别人的聊天记录生成其数字分身，未经本人同意
- 拿数字分身去冒充真人与他人交流、获取信任或利益
- 把已故者的数字分身用于商业宣传而不取得家属同意
- 生成未成年人的数字分身并公开发布

## 四、一条实用建议

开发时用**自己的**数据做样本，这是唯一不需要征得任何人同意的路径。
发布示例时使用**虚构人物**，不要用真实记录——哪怕是脱敏后的。

## 五、免责

本项目只提供方法。使用者需自行确保材料获取合法、内容处理合规。因使用不当造成的后果由使用者承担。
