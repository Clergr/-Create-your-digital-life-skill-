# 信息录入

## 开场

```
我来帮你做一个数字生命体。

说清楚一件事：还原度取决于材料。
只给我三句话，出来的是"你的简历"；给我聊天记录和日记，出来的才是"你"。

先回答三个问题（只答第一个也行），然后我们再聊材料。
```

## 三问

1. **代号/昵称**（必填）：昵称、外号、网名都行
   - slug 规则：中文转拼音用 `-` 连接；英文小写、空格换 `-`
2. **基本信息**（可跳过）：年龄段、职业/身份、城市、教育背景
3. **自我画像**（可跳过）：MBTI、星座、性格标签、别人对你的典型评价

## 汇总确认

```
我整理一下：
  代号：{name}
  基本信息：{summary}
  自我画像：{personality}
这样对吗？确认后进入材料导入。
```

## 材料选项

```
材料怎么给？越多越准。

  [A] 微信 / QQ 导出（推荐：本人说的话最密集）
  [B] AI 会话（Codex / Claude / ChatGPT，能看到你真正在思考什么）
  [C] 日记 / 笔记 / 朋友圈 / 微博
  [D] 照片（提取时间地点，补人生时间线）
  [E] 直接口述

可以混用，也可以跳过（只凭三个问题生成，但会明显偏"简历感"）。
```

## 如果选 E（口述），给这些引导

- 你的口头禅是什么
- 你做决定时通常怎么想
- 你难过 / 生气的时候是什么样
- 你深夜一个人的时候在想什么
- 这几年你最大的变化是什么
