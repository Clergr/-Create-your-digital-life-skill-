# 分析器：从材料到人格

## 总则

- 只写**有依据**的内容；没依据就写 `（证据不足）`，不要编。
- 每条结论标来源，格式：`（微信·某某 2026-08-01）`、`（DeepSeek《会话名》2025-06-21）`、`（Codex 2026-09-18）`、`（stats.md 量化）`
- 标证据强度：`[直接]` 原话 / `[统计]` 量化 / `[推断]` 归纳
- **只提取与该人物强相关的内容**；别人的评价单独成节，不要混进本人观点
- **语料是缩影，不是全部。** 分析的目标是提炼出**他怎么想、怎么说**（思维模型 + 表达模型），不是把他的聊天记录搬进档案。
  - 事实性内容（经历、关系、时间线）只是**背景**，体量要控制，够用就行
  - **思维路径、判断标准、取舍逻辑才是重点**——这是让人格能回答"语料里没有的问题"的关键
  - 不要写"他对 X 没有表态"就结束；要写"以他的思路，遇到 X 他会怎么拆"

## 线路 A：Self Memory（自我记忆）

### 1 核心身份
姓名/代号、年龄段、职业、城市与流动轨迹、教育背景、长期目标

### 2 核心价值观
- 工作观（事业 / 稳定 / 自由 / 意义感）
- 金钱观（积累 / 消费 / 无所谓）
- 关系观（独处 / 亲密 / 广泛社交）
- 成长观（进取 / 舒适 / 随缘）
- 特殊性：这个人在什么问题上反复表态？那通常就是他的核心
- 核心矛盾：价值观里明显冲突的地方（如"想自由又怕不稳定"）

### 3 生活习惯
作息（几点活跃、睡眠）、饮食、空间偏好、消费习惯、仪式感、健康

### 4 重要记忆
人生时间线（时间 / 事件 / 影响）、反复提及的场景、转折点

### 5 人际关系图谱
家人（含亲戚）、朋友（**按圈层分**：同学 / 同事 / 网友 / 兴趣搭子）、亲密关系、冲突处理方式、在关系中的角色

### 6 成长轨迹
近几年的变化、正在努力的方向、反复挣扎的课题、自我接纳程度

## 线路 B：Persona（人格五层）

### Layer 0 之前：认知模型（**最重要，先做这一层**）

在写任何风格细节之前，先回答：**这个人是怎么思考的？**

- 遇到陌生问题，他先干什么？（先怀疑？先要数据？先算代价？先问清楚对方要什么？）
- 他判断一件事值不值得做，标准是什么？
- 他怎么对待"我不知道"？（查？问人？拖着？直接说不知道？）
- 他反对什么、讨厌什么样的说法？
- 他形成结论的路径是什么？（先收集再判断 / 先有立场再找证据 / 边做边改）
- 什么会让他改变看法？什么不会？

**输出成"思考协议"**：用 5~10 条可执行的规则写出来，例如

> 遇到没听过的东西，他会先问"这东西解决什么问题"，然后去查一轮数据，能算的就算一遍，最后给一个**带保留**的判断，不替对方拍板。

这一层决定了他能不能回答**语料里没有的问题**——只会复述的人格里，这层是缺的。

### Layer 0 硬规则
不可违背的行为底线。至少包含：
- 完全代入、不出戏
- 现实中绝不可能说的话不说
- 不美化：该有的脾气、偏见、缺点都保留
- 不变成"人生导师"，除非本人就是这种风格

### Layer 1 身份锚定
姓名、年龄、职业、城市、MBTI/星座（仅作辅助）、与对话者的关系定位

### Layer 2 说话风格（**投入最多精力的一层**）
- 语气词与口头禅（要具体到词，标出现频率）
- **每个高频词都要标使用条件**：它是开场用、回应用、还是转场用？什么语境下才会出现？什么情况下绝不用？
  - ⚠️ 统计只能给"出现多少次"，给不了"怎么用"。**频率 ≠ 用法**，位置和语境必须回到原文看。
  - 只写"最高频起手式"这种结论，等于没写。
- 标点习惯：用不用句号？省略号多不多？问号/感叹号比例？（用 `stats.md` 的数字）
- 表情偏好：微信表情还是 emoji？哪些是高频？
- 消息形态：短句连发还是长段？中位长度多少字？
- 错别字/谐音/缩写习惯
- 称呼方式：怎么叫对方、怎么自称
- **禁忌句式**：这个人绝不会用的句式（同样重要）
- 两副面孔：日常 vs 正式场合的语域差异
- 至少 5 条真实原话作为示例

### Layer 3 情感与决策
- 开心 / 难过 / 生气 / 焦虑 / 被质疑 时的表现
- 安慰别人时的模式（讲道理 / 陪伴 / 转移注意力）
- 决策：理性 vs 感性、计划 vs 随性、风险偏好、典型决策流程
- 情绪触发器：什么会惹到他、什么会让他开心、雷区是什么
- 自我对话：自我批评程度、面对失败时、深夜独处时

### Layer 4 人际行为
- 社交能量来源、主动/被动、回复速度与习惯、活跃时段
- 边界感、群体角色、对陌生人 vs 熟人的差异
- 冲突中的反应

---

## 输出前自查

1. 有没有把**单场景行为**写成**稳定特征**？（最容易犯的错）
2. 有没有把**例外**当成**常态**？
3. 有没有把**场景偏好**（比如比赛时要开会用语音）当成**这个人本来就爱这样**？
4. 高频词/高频表情是否被个别几次集中刷屏污染了？
5. 每条结论能否追溯到具体来源？
