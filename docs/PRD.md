# 产品说明（PRD）

## 1. 一句话

给一份人的数据，还一个会说话的人。

## 2. 解决什么问题

现有的"人格 prompt"都是**写出来的**——作者凭印象描述一个人，因此：

- 不可验证：不知道依据来自哪里
- 不可迁移：换个人要重写
- 不真实：容易写成"更好的自己"而不是"真实的自己"

本产品把这件事变成**流程**：数据 → 分析 → 生成 → 验收 → 迭代。同一套流程，换数据就换人。

## 3. 目标用户

| 用户 | 场景 |
|---|---|
| 想认识自己的个人 | 把自己的聊天记录、日记、AI 会话蒸馏成一版"自我镜像"，用于自我复盘 |
| 创作者 | 为小说 / 剧本 / 游戏生成有真实感的角色人格 |
| 研究者 | 研究人格建模、语言风格迁移 |
| 团队 | 把某个角色的表达规范固化成可复用技能 |

## 4. 核心能力

1. **多源摄取**：微信（WeFlow txt / chatlab jsonl）、QQ、AI 会话（Codex / Claude / 通用 jsonl）、日记笔记、照片 EXIF
2. **量化画像**：消息长度、活跃时段、标点习惯、口头禅、表情偏好、长消息样本
3. **双层建模**：Part A 自我记忆（是什么）+ Part B 人格五层（怎么说、怎么想）
4. **认知模型优先**：先写"思考协议"，让人格能回答语料外的问题，而不是只会复述
5. **完全代入运行**：生成物可直接对话，禁止元评论与免责说明
6. **可进化**：追加素材合并、对话纠正、版本备份与回滚
7. **多人物并存**：一个仓库/技能目录下管理任意多个数字生命体

## 5. 关键设计决策

| 决策 | 原因 |
|---|---|
| 语料只做"校准"，不做"知识库" | 否则人格退化成检索器，遇到语料外问题就答不出 |
| 认知模型放在 Layer 0 之前 | 决定人格能否迁移到新话题 |
| 明确写"禁忌句式" | 高频词只说明频率，不说明用法；写清什么绝不说，比列口头禅更有效 |
| 允许联网但必须"消化成我的认知" | 保持人物口吻，避免切换成百科腔 |
| 版本快照里 SKILL.md 改名为 `.archived` | 运行时递归扫描技能目录，否则会重复注册同名技能 |

## 6. 验收标准

- 五场景盲测通过（熟人日常 / 被问未来 / 给建议 / 被质疑 / 陌生人问私事）
- 语料外问题能给出"像本人一样推理且带保留"的回答
- 全程无出戏（不出现"根据记录/资料显示/这是推测"）
- 仓库零真实个人信息；发布前自检通过

## 7. 不做什么

- 不做"完美人格"：不美化、不修饰棱角
- 不替使用者判断伦理对错：这是自我观察工具，不是对外冒充工具
- 不代替使用者承担合规责任：素材合法性、他人隐私由使用者负责
